# Phần Mềm Quản Lý Thu Phí & Cư Dân Chung Cư BlueMoon

Hệ thống quản lý chung cư xây dựng bằng **Node.js + PostgreSQL + React**.

## Cấu trúc Tài nguyên CSDL
- [Tài liệu chi tiết CSDL (DATABASE.md)](./DATABASE.md)
- [Kịch bản khởi tạo CSDL SQL](./database/schema.sql)
- [Dữ liệu mẫu](./database/seed.sql)

## Khởi tạo nhanh CSDL
1. Tạo Database `bluemoon_db` trên PostgreSQL.
2. Chạy file `database/schema.sql` trong pgAdmin hoặc psql.
3. Chạy file `database/seed.sql` để có dữ liệu mẫu và tài khoản Admin (xem [DATABASE.md](./DATABASE.md)).
